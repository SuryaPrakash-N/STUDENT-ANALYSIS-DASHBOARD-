# 🎓 Student Analysis Dashboard Using Microsoft Excel

## 📌 Project Overview
The **Student Analysis Dashboard** is an interactive Excel-based data analysis project designed to analyse student academic performance and student-related information.

This project uses Microsoft Excel to visualize and understand student marks, attendance, grades, courses, branches, gender, and hostel/day scholar details through charts, PivotTables, and interactive slicers.

## 🎯 Project Objectives
- Analyse student academic performance.
- Calculate total, minimum, and average marks.
- Analyse student attendance.
- Compare marks across different courses and branches.
- Understand grade distribution and pass/fail results.
- Analyse student information based on gender.
- Create an interactive dashboard for easy data visualization.

## 🛠️ Tools & Technologies Used
- Microsoft Excel
- Excel PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Visualization

## 📊 Dashboard Features

### 1. KPI Cards
The dashboard displays important performance indicators:
- Total Marks: 3808
- Minimum: 30
- Average: 20.4068
- Total Attendance: 3203

### 2. Charts and Visualizations
- **Marks by Course:** Compares marks across different courses.
- **Pass/Fail Analysis:** Displays the distribution of pass and fail results.
- **Attendance Analysis:** Compares attendance between hostel students and day scholars.
- **Marks by Branch:** Visualizes branch-wise marks distribution.
- **Grade Analysis:** Displays the distribution of grades.
- **Gender Analysis:** Shows age-related information by gender.

### 3. Interactive Slicers
The dashboard includes the following filters:
- Course
- Branch
- Hostel/Day Scholar
- Grade
- Gender

These slicers allow users to filter the dashboard and explore different categories of student information.
